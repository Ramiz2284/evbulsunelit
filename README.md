# EvBulsun 🏠

**Обратная доска объявлений для поиска жилья.**  
Арендаторы и покупатели описывают, что ищут — владельцы жилья находят их и пишут напрямую через Telegram.

---

## Как работает

1. Пользователь заполняет форму (город, бюджет, пожелания, способ связи)
2. Запрос публикуется в Telegram-канал через Bot API
3. Владельцы жилья, подписанные на канал, видят запросы и пишут напрямую
4. Никакого бэкенда, никакой базы данных — только статичный сайт

**Конфиденциальность:** пользователь сам выбирает контакт — Telegram username (без номера телефона), WhatsApp или email.

---

## Стек

- **React 18** + **Vite**
- Telegram Bot API (публикация в канал)
- Деплой на **Vercel** (статика, бесплатно)

## Локальная разработка

```bash
# 1. Установить зависимости
npm install

# 2. Создать файл с переменными окружения
cp .env.example .env.local
# Откройте .env.local и вставьте свои токен и ID канала

# 3. Запустить dev-сервер
npm run dev
# Сайт откроется на http://localhost:5173
```

## Настройка Telegram

### Шаг 1 — Создать бота

1. Откройте [@BotFather](https://t.me/BotFather) в Telegram
2. Отправьте `/newbot`
3. Придумайте имя и username для бота
4. Скопируйте **токен** (вида `1234567890:ABCdef...`)

### Шаг 2 — Создать канал

1. Создайте новый канал в Telegram (публичный или приватный)
2. Зайдите в настройки канала → Администраторы
3. Добавьте вашего бота как администратора с правом **публикации сообщений**
4. Запомните **@username** канала (или числовой ID, если канал приватный)

### Шаг 3 — Добавить переменные окружения

**Для локальной разработки** — в файл `.env.local`:
```
VITE_TELEGRAM_BOT_TOKEN=ваш_токен
VITE_TELEGRAM_CHANNEL_ID=@ваш_канал
```

**Для Vercel** — см. раздел ниже.

## Деплой на Vercel

### Способ 1 — через сайт Vercel (рекомендуется)

1. Залейте проект на GitHub (см. ниже)
2. Зайдите на [vercel.com](https://vercel.com) и войдите через GitHub
3. Нажмите **Add New → Project**
4. Выберите ваш репозиторий `evbulsun`
5. Vercel автоматически определит Vite — настройки менять не нужно
6. Перед деплоем добавьте переменные окружения:
   - **Settings → Environment Variables**
   - Добавьте `VITE_TELEGRAM_BOT_TOKEN` = ваш токен
   - Добавьте `VITE_TELEGRAM_CHANNEL_ID` = @ваш_канал
7. Нажмите **Deploy**

После этого любой пуш в `main` будет автоматически деплоиться.

### Способ 2 — через Vercel CLI

```bash
npm install -g vercel
vercel login
vercel --prod
# Введите переменные окружения когда спросит
```
